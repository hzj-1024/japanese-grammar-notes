# 日文文法小筆記

這是一份給 JLPT N5～N4 程度使用的文法小筆記網站。每一篇都用同一套格式來寫，之後要加新頁面時，照 `AGENTS.md` 的步驟做就好。

## 怎麼看

用瀏覽器直接打開 `index.html` 就可以，不需要安裝套件，也沒有 build 步驟。

公開網站：

- https://hzj-1024.github.io/japanese-grammar-notes/

## 專案裡有什麼

- `AGENTS.md`：專案規則。之後請 AI 幫忙加頁面時，先把這份給它看。
- `templates/grammar-template.html`：新增文法頁時要複製的模板。
- `grammar/`：一則文法一篇網頁。
- `index.html`：目錄首頁，可依級別篩選、用關鍵字搜尋。
- `log.md`：改動紀錄。

## 想加一篇新的文法

先讀 `AGENTS.md`，再複製模板開始寫。寫完記得更新首頁卡片、前後篇連結，以及 `log.md`。
